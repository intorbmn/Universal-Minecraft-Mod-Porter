# Phase 11 — User Interface (Tauri) Implementation Plan

> **For agentic workers:** Native execution (user's choice, 2026-11-20): use `superpowers:executing-plans` with
> `superpowers:test-driven-development`. Steps use checkbox syntax. Ledger: `.superpowers/sdd/phase11-ui/progress.md`
> (every deviation as `Ruling: <decision> — <why> — <cost if wrong>`).

**Goal:** A Tauri desktop app (Svelte front-end) whose every action is a tested application service in `core/src/app/`; the CLI uses the same services.

**Architecture:** `ui/src` (Svelte, `invoke` only in `lib/api.ts`) → `ui/src-tauri` (separate Cargo workspace, one-line commands, keyring, event forwarder) → `core/src/app/` (`AppServices`, jobs, events, approvals) → existing engines.

**Tech Stack:** Rust 1.97 (root workspace), Tauri 2, Svelte 5 + Vite + TypeScript, Vitest + Testing Library, Playwright, `keyring`.

**Spec:** `docs/superpowers/specs/2026-11-20-phase11-ui-design.md` (visual direction A, Calm workbench). Scope source: `docs/guides/phase-11-ui.md`.

## Global Constraints
- The four commands pass before every commit: `cargo build --all`, `cargo test --all`, `cargo clippy --all --all-targets -- -D warnings`, `cargo fmt --all -- --check` (baseline 213 tests on master).
- Sandbox toolchain: `export PATH=/usr/lib/rust-1.97/bin:$PATH` (Rust 1.97 from apt; `static.rust-lang.org` is blocked). Never edit `rust-toolchain.toml`.
- `unsafe_code = "forbid"`; clippy pedantic + nursery as errors. No async runtime and no HTTP in `core`.
- Files change only through `MigrationEngine` after a checkpoint, or by writing into a new output folder (ADR 0005/0006).
- In-place apply needs `reviewed = true`, otherwise `AppError::Refused`. High risk blocks pack migrate and local build without an explicit acknowledgment.
- Secrets: `Secret` is not `Serialize`, prints `***`; no `get_secret` command; nothing secret in `settings.json`, logs or events.
- Every path from the UI is validated in the services (exists, right kind, `resolve_within` when combined).
- Synthetic names in fixtures and docs (`DemoWidget`); fixtures look like real inputs.
- Tauri capabilities: dialog open + opener only; CSP `default-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; connect-src ipc: http://ipc.localhost`.
- npm: exact versions, committed `package-lock.json`, `npm ci` in CI.
- Next ADR number is 0014.

## Review Focus
- Opening a path that does not exist, is a file where a folder is expected, or is an empty folder: a clear `Input` error, no panic.
- Cancel pressed while a job is waiting on an approval, and cancel pressed twice: the job ends `Cancelled`, no file is written.
- App closed while a job runs: next `open` marks it `Failed` ("interrupted"), never "Running" forever.
- A 10 000-line log and a 300-mod pack: events stay rate-limited (≤20 `job.log`/s per job); the full log is in `JobDb`.
- Output folder not empty, or inside the source: `port` refuses; the source tree is untouched.
- Vietnamese strings are longer than English: no clipped labels on the Plan & Diff screen.
